What this project does

This project pairs two kinds of data. The first is historical: specific, named Baltimore neighborhoods and the grade the federal Home Owners' Loan Corporation assigned them in 1937, each one sourced to a specific citation you can check yourself. The second is live: how many currently-open vacant building notices Baltimore City's own housing department has on file for those same neighborhoods right now, queried directly from the City's public data feed.

Putting them side by side lets you see, for these specific places, whether the pattern researchers have found citywide — that historically lower-graded areas have measurably worse outcomes today — shows up in one simple, live, checkable number.

What this project does not do

It is not the full 1937 map. The actual HOLC survey graded roughly 42 separate areas across Baltimore. This project covers five specific, well-documented named neighborhoods where a real citation states the grade explicitly — not an estimate, not an inference from a map image. That is a deliberate, narrow scope, not an oversight.

It is not proof of causation. A handful of neighborhoods showing a pattern consistent with published research is illustrative, not a new statistical finding. The peer-reviewed studies cited on the History page are the actual evidence; this tool is a live, checkable window into part of what they describe.

Vacancy notices are one indicator, not "neighborhood decline." A vacant building notice reflects a specific legal/administrative status, not a full picture of a neighborhood's health. (A companion tool in this same project family, Baltimore Vacant Property Watch, explains exactly what that status does and doesn't mean if you want more detail.)
